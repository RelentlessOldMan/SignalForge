# ADR 0337: Maximum time interval error

Status: accepted, 2026-11-18.

## Context

Network synchronization standards (the ITU-T G.810 family) state wander limits as masks on
the maximum time interval error, MTIE, as well as on the time deviation (ADR 0331). MTIE is
the largest peak-to-peak time error inside any observation window of a given length. It catches
the worst transient, which TDEV averages away.

## Decision

- **The API.**
  - Python: `mtie(time_error, sample_interval, window_sizes)` in `measurements`, giving the
    frozen dataclass `Mtie(taus, values)` (`eq=False`, as it holds arrays).
  - C#: `Measurements.Mtie(ReadOnlySpan<double> timeError, double sampleInterval,
    ReadOnlySpan<int> windowSizes)`, giving the record `Mtie(double[] Taus, double[] Values)`.
- **The value.**
  - The input is time-error samples `x[i]` in seconds, `τ₀` apart. This is phase data, not the
    fractional frequency that ADRs 0327–0331 take.
  - For each window size `n`, `τ = n·τ₀` and the window spans `n + 1` samples:
    `MTIE(τ) = max_{k=0}^{N−1−n} (max_{i=k}^{k+n} x[i] − min_{i=k}^{k+n} x[i])`.
- **The rules.**
  - `time_error` real, one-dimensional, finite and at least 2 long.
  - `sample_interval` finite and positive.
  - `window_sizes` not empty, each an integer with `1 ≤ n ≤ N − 1`, in any order.

## Consequences

- **Vectors.**
  - Each value is one float subtraction of two samples. The generator takes the maximum and
    minimum exactly in rationals, and the rounded difference equals the float one.
  - `τ` is one float product.
  - The tolerance is `abs 0, rel 1e-15`.
