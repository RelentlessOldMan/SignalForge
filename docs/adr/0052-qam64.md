# ADR 0052: 64-QAM

Status: accepted, 2026-11-13

## Context

QPSK, 8-PSK and 16-QAM have mappers, hard and soft demappers and BER theory. 64-QAM is the next
square constellation most links use.

## Decision

- `qam64_map`, `qam64_demap_hard`, `qam64_demap_llr`, `qam64_ber_theory`, `qam64_ser_theory`,
  with the 16-QAM names and arguments.
- Gray labeling per axis as 16-QAM's extended by one bit: the first bit is the sign, the other
  two a reflected Gray code of the magnitude (7, 5, 3, 1). Written as a product,
  `(1 − 2·b_a)·(4 + (1 − 2·b_b)·(3 − 2·b_c))`, so both languages compute the same integers.
- Hard decisions compare `|v|` against `2/√42`, `4/√42` and `6/√42` directly (no subtraction),
  so ties are exact and bit 0 wins them.
- The theory is the exact Gray square-QAM sum (Cho and Yoon, 2002), written out for 8-PAM; the
  vectors check it against a numerical integral over the decision intervals.

## Consequences

- No carrier loop or link support yet: 64-QAM's fourth power has a negative real mean, as
  16-QAM's does, so the link's block phases would work; its decision-directed loop is later work.
