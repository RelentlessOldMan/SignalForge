# ADR 0279: State-variable filter

Status: accepted, 2026-11-17.

## Context

A state-variable filter gives low-pass, band-pass, high-pass and notch outputs from one
second-order structure. The trapezoidal-integrator (TPT) form, written by Zavalishin and
Simper, matches the bilinear transform of the analogue prototype. Unlike a direct-form biquad it
stays well behaved when the cutoff and Q are changed from sample to sample. A later auto-wah can
drive it that way. This slice holds them fixed.

## Decision

- **The API.**
  - Python: `svf(samples, cutoff, q, sample_rate, *, output="lowpass")` in `dsp`, with
    `output` one of `"lowpass"`, `"bandpass"`, `"highpass"`, `"notch"`.
  - C#: `Dsp.Svf(samples, cutoff, q, sampleRate, output = SvfOutput.Lowpass)` with a new enum
    `SvfOutput { Lowpass, Bandpass, Highpass, Notch }`.
  - Real and complex; a complex signal is filtered part by part.
- **The coefficients.**
  - `g = tan((π·cutoff)/fs)` and `k = 1/q`.
  - `a1 = 1/(1 + g·(g + k))`, `a2 = g·a1`, `a3 = g·a2`.
- **The recursion**, from rest (`ic1 = ic2 = 0`), per sample:
  - `v3 = x − ic2`;
  - `v1 = a1·ic1 + a2·v3`;
  - `v2 = ic2 + a2·ic1 + a3·v3`;
  - `ic1 = 2·v1 − ic1`, then `ic2 = 2·v2 − ic2`.
- **The outputs.**
  - Low-pass `v2`, band-pass `v1`.
  - High-pass `x − k·v1 − v2`, notch `x − k·v1`.
- **The transfer functions** are the bilinear transform, with `s` prewarped so that `s = j` at
  the cutoff, of `1/(s² + k·s + 1)` (low), `s/(s² + k·s + 1)` (band), `s²/(s² + k·s + 1)`
  (high) and `(s² + 1)/(s² + k·s + 1)` (notch). The band-pass peak gain is therefore `q`, not 1.
- **The rules.**
  - `0 < cutoff < fs/2`, `q > 0`, `fs > 0`, all finite.
  - `output` must name one of the four.
  - The samples must be finite and at least one.

## Consequences

- **Vectors.**
  - Expected values come from the direct-form biquad of the bilinear transform. It is run in
    exact rationals at the float `g` that `math.tan` returns.
  - The generator checks `low + k·band + high = x` and `notch = low + high` exactly.
  - The tolerance is `abs 1e-13, rel 1e-12`.
- **Time-varying parameters** are left for the auto-wah slice.
