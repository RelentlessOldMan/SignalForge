# ADR 0054: Binary and M-ary FSK

Status: accepted, 2026-11-13

## Context

Every modulation so far is linear (PSK, QAM) and detected coherently. FSK is the common
constant-envelope alternative, detected without a carrier phase, and its noncoherent error rate is
a classic closed form to test against.

## Decision

- `fsk_modulate(bits, order, samples_per_symbol, modulation_index)`: continuous-phase FSK,
  `order` 2, 4, 8 or 16, natural binary labels, tone levels `2m − (M − 1)` at `a·h/2` cycles per
  symbol. It returns complex samples, not one value per symbol, because FSK is not a
  constellation: the waveform is the modulation. The phase is written as `π·h·(S_i + a·n/sps)`
  with `S_i` an exact integer sum of the past levels, so it does not drift with a running float
  sum and both languages compute it the same way.
- `fsk_demod_noncoherent(samples, order, samples_per_symbol, modulation_index)`: a square-law
  correlator bank, one block per symbol, assuming symbol timing; ties go to the smallest label.
- `fsk_ser_theory` and `fsk_ber_theory(eb_n0_db, order=2)`: the noncoherent orthogonal
  closed form. Natural binary labels are enough here: for orthogonal tones every wrong label is
  equally likely, so Gray labels would not change the bit error rate.
- `order` stops at 16: the alternating binomial sum loses about `log10(max term)` digits to
  cancellation, about 3 at 16 and far more beyond.
- Bits in and bits out, as for the PSK and QAM mappers. There is no FSK link yet; the waveform
  goes through `awgn` with `signal_power = 1`.

## Consequences

- MSK-like indices (`h = 0.5`) modulate, but the noncoherent detector and its theory assume a
  whole-number `h`; a coherent or multi-symbol detector for `h = 0.5` is later work.
- The detector needs symbol timing; FSK timing and frequency recovery are later work.
