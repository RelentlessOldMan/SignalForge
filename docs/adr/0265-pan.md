# ADR 0265: Panner

Status: accepted, 2026-11-17.

## Context

Placing a mono source between two speakers means sending it to both channels with gains set by
a position. The constant-power law keeps `gL² + gR² = 1`, so a source keeps its loudness as it
moves; at the centre each gain is `1/√2`, which is −3 dB. The linear law keeps `gL + gR = 1`
instead; at the centre each gain is `1/2`, which is −6 dB. It suits correlated signals that sum
acoustically.

## Decision

- **The API.**
  - Python: `pan(samples, position, *, law="constant_power")` in `dsp` returns
    `LeftRight(left, right)` (ADR 0264). `law` is `"constant_power"` or `"linear"`.
  - C#: `Dsp.Pan(samples, position, law = PanLaw.ConstantPower)` returns `LeftRight`, with
    `PanLaw { ConstantPower, Linear }`.
  - Real samples only.
- **The value.** `position` runs from `−1` (hard left) to `1` (hard right).
  - Constant power: `θ = (position + 1)·(π/4)`, `gL = cos θ`, `gR = sin θ`.
  - Linear: `gL = (1 − position)/2`, `gR = (1 + position)/2`.
  - `left = x·gL`, `right = x·gR`.
- **The rules.**
  - `position` must be finite and in `[−1, 1]`.
  - `law` must be one of the two names.
  - The samples must be real, finite and non-empty.

## Consequences

- **Vectors.**
  - The linear cases are exact.
  - The constant-power cases use the stdlib `math.cos` and `math.sin`.
  - The tolerance is `abs 1e-15, rel 1e-15`.
  - At `±1` the far gain is `cos(π/2)`, about `6e-17`, not 0.
