# signalforge (Python)

The Python implementation of SignalForge: signal generation, DSP and measurement, with NumPy as its
only dependency. See the
[repository README](https://github.com/RelentlessOldMan/SignalForge#readme) and the
[numerical conventions](https://github.com/RelentlessOldMan/SignalForge/blob/main/docs/conventions.md).

    pip install -e .[dev]
    pytest
